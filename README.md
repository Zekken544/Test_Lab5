## Тестийн дизайн

Тестлэх үндсэн функц нь `POST /registrations` буюу хичээлд бүртгүүлэх үйлдэл юм. Оролтын нөхцөлүүдийг ангилж, төлөөлөх утга сонгон, хүлээгдэх хариуг тодорхойлов.

### Сонголт ба төлөөлөх утга

| Сонголт | Ангилал | Төлөөлөх утга |
|---|---|---|
| Оюутны төлөв | Идэвхтэй / идэвхгүй / байхгүй | `active`, `inactive`, үүсгээгүй studentID |
| Үзсэн хичээлүүд | Урьдач нөхцөлийг хангана / хангахгүй | `["CS201"]`, `[]` |
| Хичээлийн бүртгэл | Байгаа / байхгүй | PUT-аар үүсгэсэн courseID, үүсгээгүй courseID |
| Урьдач хичээлийн биелэлт | Бүгд / огт үзээгүй / заримыг үзсэн | Шаардлага `["CS201","CS202"]` үед үзсэн хичээлүүд нь тус тус `["CS201","CS202"]`, `[]`, `["CS201"]` |
| Хүсэлтийн талбар | Бүрэн / дутуу | studentID ба courseID хоёулаа / courseID байхгүй |

Оюутны бичлэг байхгүй үед түүний идэвх болон үзсэн хичээлийг бодит өгөгдлөөр тохируулах боломжгүй. Хичээл байхгүй үед урьдач нөхцөлийг нь шалгах боломжгүй. Ийм нөхцөлүүдийг бие даасан хүчинтэй хослол гэж тооцоогүй.

### Тестийн тохиолдлууд ба хүлээгдэх үр дүн

| № | Нөхцөл | HTTP статус | result |
|---|---|---:|---|
| 1 | Идэвхтэй оюутан урьдач нөхцөлийг хангана | 201 | `OK` |
| 2 | Оюутан байхгүй, хичээл байгаа | 200 | `ERROR_NO_STUDENT` |
| 3 | Оюутан идэвхгүй, хичээл байгаа | 200 | `ERROR_INACTIVE_STUDENT` |
| 4 | Идэвхтэй оюутан байгаа, хичээл байхгүй | 200 | `ERROR_NO_COURSE` |
| 5 | Идэвхтэй оюутан урьдач хичээлүүдийн заримыг үзсэн | 200 | `ERROR_PREREQUISITES` |
| 6 | Оюутан болон хичээл хоёулаа байхгүй | 200 | `ERROR_NO_STUDENT` |
| 7 | Оюутан идэвхгүй, хичээл байхгүй | 200 | `ERROR_INACTIVE_STUDENT` |
| 8 | Үзсэн хичээлгүй оюутан урьдач нөхцөлгүй хичээлд бүртгүүлнэ | 201 | `OK` |
| 9 | courseID талбар дутуу | 400 | `ERROR_BAD_REQUEST` |

Эдгээр нь төлөвлөсөн хүлээлт бөгөөд гүйцэтгэлийн үр дүнг Newman-аар шалгана. Давхар алдаатай 6, 7-р тохиолдлын хүлээлтийг серверийн шалгалтын дарааллаас гаргасан.

Тохиолдол бүр өөрт хэрэгтэй өгөгдлөө setup хүсэлтээр үүсгэнэ. Байхгүй байх ёстой ID-г бусад setup хүсэлтэд ашиглахгүй. Амжилттай бүртгэлийн ID-г тогтмол тоотой харьцуулахгүй, тоон төрөлтэй эсэхийг шалгана.
